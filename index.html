FAQ

Frequently Asked Questions

What exactly does this tool do?
It generates professional ROI/impact reports for AI automation agency clients. You input the client's monthly invoice, hours saved, revenue increases, and cost reductions — and it produces a polished markdown report showing value delivered, ROI percentage, payback period, and annualized projections. Perfect for retention conversations and upsell proposals.
Do I need to install anything?
No. The tool uses only Python's standard library — no pip install, no requirements.txt, no virtualenv required. If you have Python 3.6+ installed (which comes pre-installed on macOS and most Linux systems), you can run it immediately. Windows users download Python from python.org.
Can I process multiple clients at once?
Yes! Use --batch clients.csv to process your entire client portfolio in one command. Each client gets an individual markdown report, and a summary CSV is generated with every metric for portfolio-level analysis.
What metrics does it calculate?
Monthly value delivered, total value to date, labor cost savings (with scalability multiplier), revenue increases, cost reductions, net ROI dollars, ROI percentage, value-to-cost ratio, payback period in months, annualized value projection, total hours saved, and effective hourly rate of saved hours.
What formats does it output?
Professional markdown reports (ready to email), JSON data files (for API/dashboard integration), and CSV summaries (for portfolio analysis). The markdown reports include an executive summary, value breakdown table, efficiency metrics, annualized projections, and key takeaways.
